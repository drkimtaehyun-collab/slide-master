# 저장 위치 · 동의 절차 체크리스트

진료 녹음에는 건강정보(개인정보보호법상 **민감정보**)와 음성(식별 가능한 개인정보)이
함께 담깁니다. 자동 처리를 켜기 전에 아래 항목을 정하고 기록해 두세요.

> 이 문서는 운영 체크리스트이며 법률 자문이 아닙니다. 병원 개인정보 보호책임자,
> 의사회·병원협회 가이드, 필요 시 법률 전문가 확인을 거쳐 확정하세요.

## 1. 데이터 흐름 — 무엇이 어디로 가는가

| 데이터 | 처리 위치 | 외부 전송 |
|---|---|---|
| 녹음 파일(음성) | 진료실 PC 로컬 (`faster-whisper`) | **없음** |
| 녹취록 원문 | 진료실 PC 로컬 (`clinic/work/`) | 없음 |
| 마스킹된 녹취록 | Claude Code → Anthropic API | **있음** (요약 생성 시) |
| 요약 초안 | 진료실 PC 로컬 (`clinic/charts/`) | 없음 |

- 외부로 나가는 것은 **주민번호·전화번호 등을 가린 녹취 텍스트**뿐입니다.
  단, 이름·주소·병력 서술 등은 자동 마스킹으로 완전히 지워지지 않을 수 있으므로
  "가명처리된 건강정보가 외부 AI 서비스로 전송된다"는 전제로 동의·고지를 설계합니다.
- 해당 전송은 개인정보 **처리위탁**이며, 서버가 국외에 있으므로 **국외 이전** 고지
  대상이 될 수 있습니다. 개인정보 처리방침에 수탁자(Anthropic)·이전 국가·항목·
  보유기간을 기재할지 확인하세요.
- Anthropic 상용/API 약관의 데이터 보관 기간, 학습 사용 여부, 무보관(Zero Data
  Retention) 옵션 적용 가능 여부를 계약 시점 기준으로 확인해 기록하세요.

## 2. 저장 위치

- [ ] 작업 폴더는 진료실 PC의 **로컬 디스크**에 둡니다. OneDrive·iCloud·Dropbox·
      Google Drive 등 **클라우드 동기화 폴더 안에 두지 않습니다.**
      다른 곳을 쓰려면 `CHART_WORKSPACE` 환경변수로 경로를 지정합니다.
- [ ] 디스크 암호화(Windows BitLocker / macOS FileVault)를 켭니다.
- [ ] PC 로그인 계정을 진료 담당자 전용으로 두고, 화면 잠금을 설정합니다.
- [ ] `clinic/` 폴더는 `.gitignore`로 제외되어 있습니다. 이 저장소를 GitHub 등에
      push해도 환자 데이터는 올라가지 않지만, 폴더를 수동으로 복사·공유하지 않습니다.
- [ ] 파일명에는 환자 이름 대신 **차트번호나 접수번호**를 씁니다
      (예: `inbox/재진/C12345_0930.m4a`). 파일명은 외부로 전송되지 않지만 로그에 남습니다.

## 3. 보관 · 파기

- [ ] **녹음 원본**: 요약 확인 후 보관 기간을 정합니다. 권장은 EMR 입력 확인 후 단기
      보관(예: 7일) 뒤 파기. `watch_inbox.py --delete-audio`로 처리 즉시 삭제하거나,
      `--purge-days N`으로 N일 지난 원본·녹취록을 자동 삭제할 수 있습니다.
- [ ] **녹취록**(`clinic/work/`): 녹음과 같은 기간으로 파기합니다.
- [ ] **요약 초안**(`clinic/charts/`): EMR에 옮긴 뒤에는 정식 기록이 EMR이므로
      초안 보관 여부를 정합니다. 초안을 진료기록으로 쓰는 경우 의료법상 진료기록
      보존 기간을 따릅니다.
- [ ] 파기 기록(언제, 무엇을, 누가)을 남길지 정합니다.

## 4. 환자 동의 · 고지

- [ ] 녹음 전 **구두 설명 + 서면(또는 전자) 동의**를 받습니다. 동의서 예시:
      [`consent-form.md`](consent-form.md).
- [ ] 동의 항목: 녹음 목적(진료기록 작성 보조), 처리 방식(로컬 전사, 텍스트의 외부
      AI 요약), 보유기간, 거부 권리와 **거부해도 진료에 불이익 없음**.
- [ ] 건강정보는 민감정보이므로 일반 개인정보 동의와 **별도로** 동의를 받습니다.
- [ ] 거부한 환자는 녹음하지 않습니다. 진료 중 철회하면 즉시 녹음을 중지합니다.
- [ ] 보호자·동행인 음성이 녹음될 수 있으면 그들에게도 알립니다.
- [ ] 미성년자·의사결정능력 제한 환자는 법정대리인 동의 절차를 따릅니다.
- [ ] 대기실·진료실에 "진료 내용 녹음 및 AI 요약 사용" 안내문을 게시합니다.

## 5. 운영

- [ ] 요약은 **초안**입니다. 담당 의사가 읽고 수정한 뒤에만 EMR에 입력합니다.
- [ ] 처음 2주 정도는 요약과 녹취록을 대조해 오류 유형을 확인하고, `rules.md`,
      양식, `vocabulary.txt`를 보완합니다.
- [ ] 실패 파일(`clinic/failed/`)은 매일 확인합니다.
- [ ] 직원 교육: 누가 inbox에 파일을 넣고, 누가 요약을 확인하는지 정합니다.
