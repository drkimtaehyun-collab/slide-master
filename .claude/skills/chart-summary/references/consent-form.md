# 진료 녹음 및 AI 요약 활용 동의서 (예시)

<!-- 병원 이름, 보유기간, 수탁자 정보를 채우고 병원 개인정보 보호책임자 검토 후 사용하세요. -->

**○○의원**은 진료 기록을 정확하고 빠르게 작성하기 위해, 환자분의 동의를 받아 진료 중
대화를 녹음하고 인공지능(AI)으로 요약 초안을 만듭니다.

| 항목 | 내용 |
|---|---|
| 목적 | 진료기록 작성 보조 (담당 의사가 확인·수정 후 진료기록에 반영) |
| 수집 항목 | 진료 중 대화 음성, 음성을 변환한 텍스트 (증상, 병력, 복용 약 등 건강정보 포함) |
| 처리 방법 | 음성은 병원 내 컴퓨터에서만 텍스트로 변환합니다. 주민번호·연락처 등을 가린 텍스트가 요약을 위해 AI 서비스(Anthropic, 미국)로 전송됩니다. |
| 보유 기간 | 녹음 원본 및 변환 텍스트: 요약 확인 후 ○일 이내 파기 |
| 거부 권리 | 동의하지 않으셔도 되며, **거부하셔도 진료에 어떠한 불이익도 없습니다.** 진료 중에도 언제든 녹음 중지를 요청하실 수 있습니다. |

□ 위 내용을 설명 듣고 이해했으며, 진료 녹음에 동의합니다.
□ 건강정보(민감정보)가 포함된 텍스트를 위와 같이 AI 요약에 활용하는 것에 동의합니다.
