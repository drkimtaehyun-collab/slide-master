# 요약 규칙

아래 규칙은 양식보다 우선합니다.

1. **녹취록에 근거한 내용만 적습니다.** 언급되지 않은 항목은 `언급 없음`으로 둡니다.
   정상 소견을 추정해 채우지 않습니다 (예: "폐음 깨끗함"을 말하지 않았으면 쓰지 않음).
2. **숫자는 들은 그대로 적습니다.** 혈압, 체온, 용량, 기간, 검사 수치가 불분명하면
   값 뒤에 `[?]`를 붙이고 `확인 필요` 항목에 올립니다.
3. **화자 구분**: 녹취록에는 화자 표시가 없을 수 있습니다. 질문·설명·처방 발화는
   의사, 증상 호소는 환자/보호자로 문맥상 판단하되, 판단이 애매해 의미가 달라지는
   경우 `확인 필요`에 올립니다.
4. **진단은 의사가 말한 것만** 적습니다. 의사가 언급하지 않은 감별진단이나 추천을
   덧붙이지 않습니다.
5. **약품명**은 들린 대로 적되, 전사 오류로 보이면 가장 가까운 약품명 뒤에 `[?]`를 붙입니다.
6. **문체**: 차트 문체(개조식, 명사형 종결)로 간결하게 씁니다. 의학 약어(C.C., P.I.,
   Hx, F/U, PRN 등)는 병원 양식에 있으면 사용합니다.
7. **식별정보**: `[이름]`, `[주민번호]`, `[전화번호]` 같은 마스킹 표기는 그대로 둡니다.
   녹취록에 이름이 나와도 요약에는 쓰지 않습니다.
8. **잡담·행정 대화**(수납, 예약 시간 조정 등)는 진료에 영향이 없으면 생략합니다.
   다음 예약일처럼 계획에 해당하는 내용은 남깁니다.
9. **출력**: 양식의 제목 구조를 그대로 따르는 마크다운만 출력합니다. 앞뒤 인사말,
   설명, 코드블록 감싸기를 하지 않습니다. 양식 안의 `<!-- -->` 주석은 작성 지침이며
   출력에 포함하지 않습니다.
10. 마지막 줄에는 항상 `> 자동 생성 초안 — 담당 의사 확인 전 EMR 입력 금지`를 둡니다.
